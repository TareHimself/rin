# NodeGraphTest

Node graph views built from the engine's view system: `GraphView`, node and pin views (text and color picker pins), pin types and connection attempt events. Opens one window titled "Yoga Demo" containing a `GraphView`.

```
dotnet run --project Examples/NodeGraphTest/NodeGraphTest.csproj
```

References: Rin.Core, Rin.Graphics.Vulkan, Examples.Common.
