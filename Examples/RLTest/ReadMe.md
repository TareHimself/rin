# RLTest

Scratch console program for `HostImage`: loads a JPEG, draws it onto a 1000x1000 RGBA8 image and saves `out4.png`. The input path is hardcoded to a file in one developer's Downloads folder (see `Program.cs`), so edit it before running.

```
dotnet run --project Examples/RLTest/RLTest.csproj
```

References: Rin.Core.
