# RenderGraphViewer

Sample app for [RenderGraphOverlay](../RenderGraphOverlay/ReadMe.md): a window with a little content and the overlay attached and open. Press Capture to snapshot a frame. The graph it shows is the one that draws the viewer itself.

```
dotnet run --project Examples/RenderGraphViewer/RenderGraphViewer.csproj
```

References: Examples.Common, RenderGraphOverlay.
