# Rin.Native

Core native helpers for the engine. Builds `Rin.Native` as a shared library and packs it as `TareHimself.Rin.Native`.

## Where it fits

- `Engine/Rin.Core` references the `TareHimself.Rin.Native` package.
- `Engine/Rin.GLTF.Tests` uses the NativeAOT fake of it, see [../Fakes/ReadMe.md](../Fakes/ReadMe.md).

## Start here

- `CMakeLists.txt`: links `webmdx` and `msdfgen`.
- `conanfile.py`: requires `webmdx/1.0.0`, `harfbuzz/11.4.1` and `msdfgen/1.12`.
- `src/`: `memory.*`, `platform.*`, `sdf.*`, `video.*`, `flags.hpp`, `macro.hpp`.
- `project.csproj`: shell project used only by `dotnet pack`.

## Build and pack

From the repo root:

```
uv run task pack-native
```

Or from this folder, `uv run task build` (Release) or `uv run task buildd` (Debug). `specs/Release.nuspec` is regenerated by the CMake post-build step. See [../ReadMe.md](../ReadMe.md) for the packing flow.
